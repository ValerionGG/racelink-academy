# Renault Clio V restylée · France, 2025

[Ouvrir le dossier](https://valeriongg.github.io/racelink-academy/clio-5-2025.html) · [Habitacle photographié](https://valeriongg.github.io/racelink-academy/clio-5-2025.html?photo=cockpit#photos) · [Place conducteur en 3D](https://valeriongg.github.io/racelink-academy/clio-5-2025.html?vue=cockpit#atelier) · [esprit Alpine hybride](https://valeriongg.github.io/racelink-academy/clio-5-2025.html?finition=esprit-alpine&moteur=etech145#versions)

Le [tarif France du 1er juillet 2025, page 6](https://media.renault.com/wp-content/uploads/2025/07/959031faf015d3e963109a43f05d55df.pdf#page=6), documente quatorze couples finition–motorisation pour les voitures particulières. Les équipements et dessins cotés proviennent de la [brochure Renault, phase 2](https://cdn.group.renault.com/ren/fr/product-plans/clio-ph2/Brochure_Clio_mai_2025.pdf.asset.pdf/b560ce39fc.pdf). Les photos figurent avec leurs dates, auteurs et licences dans la [galerie de crédits](../../site/clio-v/photos/photos.json).

Dans le [configurateur Renault Maroc](https://www.renault.ma/vehicules-hybrides/clio/configurateur.html), le modèle observé était une Clio phase 2 MY25. Le passage en mode 360°, le bouton volant et le changement de direction du regard dans l’habitacle ont été essayés sous Chrome. Les finitions de ce configurateur appartiennent au marché marocain. Le [manuel français Renault de mars à septembre 2025](https://www.user-manual.renault.com/fr/notice/13326/index) documente les commandes et certains organes ; la fiche donne aussi les deux autres éditions qui recoupent l’année 2025.

Les huit vues locales utilisent une reconstitution RaceLink de la carrosserie et de l’habitacle, et des clichés issus de ce même modèle lorsque WebGL est indisponible. La [recette de fabrication](rebuild/README.md) reconstruit le GLB livré (531 112 octets ; SHA-256 : `4f1c7e207906b21a7251b7c2ecca7b4e30f4ca49f05cd95168c61b80639f1603`). Ce fichier ne contient ni la géométrie industrielle Renault, ni un éclaté moteur ; ses surfaces et les positions intérieures sont approximatives.

Le [skill Vehicle Showroom](../../skills/racelink-vehicle-showroom/SKILL.md) a été éprouvé sur un deuxième cas (e-208 GT 156 de 2023, transition de phase). Les contrôles locaux portent sur la matrice, les six crédits photo, les deux ordres de recherche, le clavier, l’absence de résultat parasite pour la Clio IV, les deux thèmes, le rendu à 320/390/430 px et sur ordinateur ; les huit positions 3D disposent d’un repli en image. Les essais de petit écran sont des simulations de largeur, pas des essais sur téléphone physique. Aucun import vidéo pour cette livraison.
