This **Instagram Reels Dataset Sample** includes **6,850 records** and was extracted using the **Bright Data API**.

## Data Points

| Field Name | Description |
|------------|-------------|
| `url` | The unique URL of the Instagram reel. |
| `user_posted` | The username of the account that posted the reel. |
| `description` | The textual description accompanying the reel. |
| `hashtags` | A list of hashtags used in the reel. |
| `num_comments` | The number of comments on the reel. |
| `date_posted` | The date and time the reel was posted. |
| `likes` | The number of likes the reel has received. |
| `views` | The total number of views for the reel. |
| `video_play_count` | The number of times the video has been played. |
| `top_comments` | A list of top comments on the reel. |
| `post_id` | The unique identifier for the reel post. |
| `thumbnail` | The URL of the thumbnail image for the reel. |
| `shortcode` | The shortcode that uniquely identifies the reel. |
| `content_id` | The content ID associated with the reel. |
| `product_type` | The type of product associated with the reel, if any. |
| `coauthor_producers` | The usernames of co-authors or producers tagged in the reel. |
| `tagged_users` | A list of users tagged in the reel. |
| `length` | The duration of the reel video in seconds. |
| `video_url` | The URL to access the video of the reel. |
| `audio_url` | The URL of the audio used in the reel. |
| `posts_count` | The total number of posts by the user who posted the reel. |
| `followers` | The number of followers of the user who posted the reel. |
| `following` | The number of accounts the user follows. |
| `user_profile_url` | The URL of the user's Instagram profile. |
| `is_paid_partnership` | Indicates if the reel is part of a paid partnership. |
| `is_verified` | Indicates if the user who posted the reel is a verified account. |
| `profile_image_link` | The URL to the profile image of the user who posted the reel. |


## Use Cases

### 1. Social Media Trend Analysis
Analyze trending hashtags and content styles on Instagram Reels to identify emerging trends and inform marketing strategies.

### 2. Influencer Marketing Insights
Evaluate influencer engagement by analyzing likes, comments, and views to optimize collaborations and campaign strategies.

### 3. Competitive Analysis
Understand competitor content strategies by examining posting frequencies, engagement metrics, and co-author collaborations.
